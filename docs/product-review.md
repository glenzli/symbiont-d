## 权限边界

- Codex 初始环境为文件只读。命令、文件修改与额外权限请求由 `src/codex/approvals.rs` 转为界面审批；后台未授权请求会被拒绝。
- Symbiont 网页读取只接受经过目标校验的公开 HTTP(S) 文本地址，有大小和重定向限制。用户给予的站点持续授权保存在当前服务进程中，可被后续后台读取复用，服务重启后清除。这不等于一轮聊天的授权。
- 邮箱和 Drive 只读取配置的来源；来源内容会按已配置链路交给模型处理。是否存在已保存账号，不能证明凭据当前可用。
- PCP 的实际访问范围由 Console 授权控制。常规连接申请自身命名空间的贡献权限与跨范围读取；历史修复使用独立授权。此次检查未扩展授权或修改凭据。

## 本轮修复

1. 设置页统一进行输入校验和单次保存管理，覆盖公共保存按钮、表单提交和表单外昵称输入。保存时锁定相关控件，避免重复提交与切页混淆。
2. 按页保留未保存草稿，关闭设置再打开不会覆盖；标签标记未保存页。刷新页面前提示仍有草稿，草稿不写入浏览器持久存储。已保存部分与后续失败分别报告。
3. 复制、引用等操作失败不再把已送达消息改成“回复中断”，避免出现错误的重发入口。
4. 授权按钮在请求提交期间保持禁用，即使收到界面刷新；明确持续授权的真实期限和后台复用范围。非 HTTP(S) 的外部确认地址仅显示为文本。
5. 更多菜单补充可访问名称，设置主分类支持方向键导航；语音说明区分本地对话与选择性长期保留；Drive 显示账号保存状态与读取失败，避免误称连接正常。
6. 服务返回非 JSON 错误时，界面保留清晰的操作失败与 HTTP 状态；不再只显示 JSON 解析异常。
